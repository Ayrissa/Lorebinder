# Lorebinder
Менеджер лорбуков для SillyTavern: закрепление, папки, цветные хэштеги и ручной порядок.

## Возможности

1. Кнопка 📁 справа от списка «Выберите для редактирования» на странице лорбуков открывает окно со всеми вашими лорбуками.
2. Закрепление (★): закреплённые всегда сверху.
3. Папки: лорбук может лежать в нескольких папках сразу; у каждой папки свой цвет.
4. Цветные хэштеги: помогают отличать лорбуки по темам; фильтр по нескольким тегам.
5. Ручной порядок стрелками вверх/вниз (удобно и на телефоне).
6. Поиск по названию, фильтры «Все / Закреплённые / Без папки / папка».
7. Клик по лорбуку открывает его на обычной странице редактирования.
8. Экспорт и импорт данных (резервная копия).
9. Русский и английский интерфейс, ПК и мобильная версия.
